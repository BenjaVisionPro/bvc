# Catalyst Code of Conduct

Catalyst is a developer community.

We expect people to behave like adults building something together.

## Expected behaviour

- Be respectful.
- Stay on topic.
- Assume good intent where reasonable.
- Give clear context.
- Credit other people’s work.
- Accept feedback without making it everyone else’s problem.
- Help make the project easier for the next person.

## Unacceptable behaviour

Unacceptable behaviour includes:

- harassment
- discrimination
- personal attacks
- sexualised or threatening comments
- publishing private information
- repeated bad-faith arguments
- spam or unrelated self-promotion
- derailing issues, discussions, or pull requests
- abusive, insulting, or demeaning language
- behaviour that makes the project unsafe or unusable for others

## Enforcement

Maintainers may take action when behaviour harms the project or community.

Actions may include:

- asking someone to stop
- warning a participant
- hiding, editing, or removing comments
- locking discussions
- closing issues or pull requests
- restricting participation
- banning a participant from project spaces

Where possible, we prefer correction and restoration.

Where safety, legal risk, or project health requires it, maintainers may act immediately.

## Reporting

Report Code of Conduct concerns to the project maintainers.

If the repository has a private security or contact channel, use that. If not, contact a maintainer directly through the available project channels.

Reports should include:

- what happened
- where it happened
- who was involved
- any relevant links, screenshots, or context

Maintainers will review reports and respond in a way that protects the project and affected participants.

## Scope

This Code of Conduct applies in project spaces, including:

- repositories
- issues
- pull requests
- discussions
- chats
- project events
- community spaces associated with Catalyst

It also applies when someone represents the project in public.
