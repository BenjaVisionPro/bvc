# Catalyst Community

Catalyst DevKit is a free development environment for building Catalyst-based games and applications.

This community exists to help developers use Catalyst, improve Catalyst, and build better persistent multiplayer systems with it.

Good contributions are practical: clear bug reports, focused pull requests, useful examples, better documentation, testing, design feedback, and help for other developers.

We want a community that is friendly, serious, and useful.

No hype theatre. No gatekeeping. No harassment. No endless architecture arguments that never produce working code.

Build things. Explain them clearly. Help the next person.

## How to participate

You can help by:

- asking clear questions
- reporting bugs with enough context to reproduce them
- improving documentation
- sharing examples
- testing components
- proposing focused changes
- submitting pull requests
- helping other developers understand the system

## Community expectations

- Be clear.
- Be respectful.
- Stay practical.
- Give context.
- Credit work.
- Keep issues and pull requests focused.
- Disagree without turning it into a performance.
- Remember that maintainers and contributors have limited time.

## What this community is not

This community is not:

- a hype channel
- a vague feature request dumping ground
- a support entitlement queue
- a place for harassment, abuse, or bad-faith arguments
- a replacement for paid plugin support when commercial support channels exist
- a place to push unrelated products, services, or projects

## Project framing

Catalyst DevKit is the developer environment for building Catalyst-based games and applications.

That Game: Catalyst (TGC) is the proof implementation for the Catalyst ideals.

The community should support both goals without confusing them:

- Catalyst DevKit is the platform developers use.
- TGC demonstrates what the platform is meant to support.
- Contributions should improve the platform, the documentation, examples, tooling, or the proof implementation in a focused way.
