# Supporting Catalyst

Catalyst DevKit is free to use.

The project is sustained through development work, documentation, testing, examples, community contribution, and commercial Unreal Engine plugins distributed through Epic’s Fab Store.

A properly considered funding and sponsorship model has not been finalised yet.

We are not using placeholder points, tokens, badges, or informal reward systems.

## Current ways to support Catalyst

The best ways to support Catalyst right now are:

- use it
- test it
- report clear issues
- improve documentation
- contribute focused examples
- submit useful pull requests
- help other developers
- provide practical feedback from real projects
- purchase Catalyst Unreal Engine plugins when available

## Commercial model

Catalyst DevKit is free.

Catalyst Unreal Engine plugins are currently planned as purchasable plugins through Epic’s Fab Store.

Connect and Model may be included for free in the future, but that is not a current promise.

GemStone provides a non-commercial licence suitable for deployment testing. Large-scale deployment uses GemStone’s commercial licence model.
